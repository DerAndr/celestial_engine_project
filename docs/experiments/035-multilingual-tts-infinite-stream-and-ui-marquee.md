# Experiment 035: Multilingual TTS Voice Matching, Infinite Streaming Ring Buffer, and OLED Text Marquee

## Date
2026-10-11

## Goal
Resolve three critical user-reported issues:
1. Fix OLED UI overlaps and clutter (header titles colliding with badges, long telemetry text truncated or clipping).
2. Dynamically select Edge-TTS voice based on the actual response language generated by the AI (avoiding Russian voice on English replies).
3. Eliminate audio cut-offs on long answers via a streaming circular ring buffer, while streaming and displaying the full response transcript as a running marquee across the OLED display.
4. Implement intuitive 3-stage visual state animations:
   - **Recording (Listening):** Inward acoustic vortex into a pulsing bright red `REC` center indicator.
   - **Transmitting / Processing:** Concentric orbital radar ping / Sub-Etha telemetry scanner.
   - **Speaking (Broadcasting):** Sonic shockwaves rippling from center outward to the outer ring boundaries.

## Architecture & Code Changes

### 1. Dynamic TTS Language Matching (`tools/ai_brain_server.py`)
- STT detects user query language; LLM generates Douglas Adams-style response.
- `detect_language_from_text(ai_text)` inspects the actual output string:
  - Cyrillic characters (`\u0400`..`\u04FF`) -> `ru-RU` (`ru-RU-SvetlanaNeural`).
  - German vocabulary -> `de-DE` (`de-DE-ConradNeural`).
  - English/Default -> `en-US` (`en-US-ChristopherNeural`).
- Sanitized punctuation (`—`, `–`, `’`, `”`) to prevent Edge-TTS websocket 403 errors.

### 2. Streaming Circular Ring Buffer (`firmware/src/audio.c`, `audio.h`, `net_client.c`)
- Removed the fixed 380,000-byte audio clamp in `ai_brain_server.py`.
- Introduced a 32,768-sample (65.5 KB, ~2.05 s) circular ring buffer (`audio_stream_ring`) mixed into I2S DMA.
- Python server paces UDP chunks at 13 ms (each 512-byte packet holds 16 ms of audio), maintaining a smooth 1-second cushion without memory exhaustion.
- Infinite audio responses now play to the final syllable.

### 3. Full-Screen Response Marquee (`firmware/src/main.c`, `net_protocol.h`)
- Added `NET_MSG_RESP_TEXT = 0x09`.
- Python server sends ASCII-transliterated response text before audio playback.
- `draw_speaking_screen` displays a prominent scrolling marquee (`draw_marquee`) inside a bordered text box, accompanied by a dynamic 14-band equalizer.

### 4. UI Clean-up & Alignment (`firmware/src/main.c`)
- Compacted `MODE_NAMES` and tags (`[RU|42]`, `[AUT|GRK]`).
- Placed header badge right-aligned at `124 - (strlen(badge) * 6)`, eliminating collisions with mode titles.
- Cleaned string layouts in `draw_listening_screen`, `draw_processing_screen`, `MODE_STATUS`, and diagnostic screens.

### 5. 3-Stage State LED Animations (`firmware/src/leds.c`, `leds.h`)
- **Listening:** `LED_ANIM_VORTEX` with center pixel glowing pulsating red (`REC active`).
- **Processing:** `LED_ANIM_DATA_RECV` with concentric data sweeps.
- **Speaking:** `LED_ANIM_EXPAND_SPEECH` with acoustic shockwaves expanding from center (core) to Ring 0, Ring 1, Ring 2, and Ring 3.
