# Experiment 001 — SH1106 OLED Display (P1)

Status: COMPLETED (PASSED)

## Goal
Validate I2C communication with the SH1106 1.3-inch 128x64 OLED display on I2C1 (GP2 / GP3), verify I2C bus scanning (address 0x3C), and render system bootscreen and staff telemetry.

## Hardware Required
- Raspberry Pi Pico 2 W (flashed with P0+ baseline)
- SH1106 1.3" 128x64 I2C OLED module (4-pin breakout: `VCC, GND, SCL, SDA`)
- 4x Dupont Female-to-Female jumper wires
- Micro-USB cable to host PC

## Confirmed Wiring Table (User Board: VCC, GND, SCL, SDA)

| OLED Pin (Left-to-Right) | Wire Color | Pico Physical Pin | RP2350 GPIO / Function | Electrical Level / Notes |
| :--- | :--- | :--- | :--- | :--- |
| **Pin 1: VCC** | **Red** | **Pin 36** (5th down from top-right) | `3V3_OUT` | **3.3 V Power** (Never connect to 5V VBUS!) |
| **Pin 2: GND** | **Black** | **Pin 3** (3rd down from top-left) | Ground | Common Ground (0 V) |
| **Pin 3: SCL** | **Yellow** | **Pin 5** (5th down from top-left) | GPIO 3 (`I2C1 SCL`) | 3.3 V I2C Clock |
| **Pin 4: SDA** | **Green** | **Pin 4** (4th down from top-left) | GPIO 2 (`I2C1 SDA`) | 3.3 V I2C Data |

## Tests & Milestones
- [x] User visually verified physical OLED pin labels (`VCC, GND, SCL, SDA`)
- [x] Firmware compiled with SH1106 driver, I2C scanner, and 5x7 font (`celestial_firmware.uf2`)
- [x] 4 Female-Female jumpers connected with USB disconnected
- [x] Pico 2 W placed in BOOTSEL mode and flashed with `celestial_firmware.uf2`
- [x] I2C bus scan detects display at address `0x3C`
- [x] Screen renders "CELESTIAL ENGINE Mk.V" banner cleanly
- [x] Screen displays live updating heartbeat ticks alongside onboard LED

## Observed Behavior
1. Automatic I2C bus scan at startup successfully located device at address `0x3C`.
2. SH1106 128x64 OLED initialized and rendered the full dashboard:
   - Outer border rectangle
   - Header: `CELESTIAL ENGINE` / `Mk.V  v0.2.0-P1`
   - Horizontal rule separator
   - Status telemetry: `STATUS: P1_ACTIVE`, `I2C: 0x3C (400kHz)`
   - Heartbeat tick counter incrementing live at 1 Hz alongside green onboard LED.
3. USB CDC serial telemetry streaming at 115200 baud on COM9 with `OLED: ONLINE`.
