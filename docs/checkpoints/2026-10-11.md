# Project State — 2026-10-11

Wrap-up checkpoint preserving prior code, experiment logs, and documentation changes.

## Confirmed Progress

- Defective audio soldering repaired by user; sound playback and rotary volume regulation confirmed operational. Retained 16-bit stereo I2S, logarithmic-like volume curve, and digital peak limit 14400. Connected to single QUARKZMAN 4 Ohm / 3 W speaker across MAX98357A differential outputs; GAIN pin floating.
- User previously **bypassed fourth ring defective LED with a jumper wire**, without desoldering. Real connection: ring DIN → top-right pad of defective LED (verified DOUT continuity). Old pad remained soldered. Not documented as an official replacement or isolated pixel bypass.
- All four rings briefly lit up in chain **7→12→24→16** with firmware 1.0.7 using PIO-paced DMA and extended reset. The fourth was connected last and powered via jumper wires from shared rail.
- User confirmed clean COSMIC SNAKE animation. In RAINBOW, occasional white flashes on individual pixels remained. In PULSAR, VOICE, and VORTEX, a faint blue-purple background was noticed on the fourth ring.
- In prepared build 1.0.10, background pixel values for those three modes were zeroed out.
