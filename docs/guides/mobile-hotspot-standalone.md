# Руководство: Автономное подключение Посоха к Телефону (Без Домашнего Wi-Fi и Raspberry Pi 5)

Celestial Engine Mk.V полностью поддерживает **100% автономную работу в полевых условиях** в связке **Только Посох (Pico 2 W) + Смартфон Android (Companion App)** — без домашней сети и без Raspberry Pi 5.

---

## 1. Архитектура автономного режима (Field Mode)

В полевом режиме смартфон выступает в роли:
1. **Точки доступа Wi-Fi (Mobile Hotspot)** — поднимает локальную сеть на частоте 2.4 ГГц.
2. **Шлюза по умолчанию (Gateway)** — IP-адрес смартфона в режиме точки доступа в Android всегда `192.168.43.1`.
3. **ИИ-Мозга (Phone Brain Server)** — мобильное приложение Celestial Companion запускает UDP-сервер на порту `5005`, транскрибирует голос с посоха, запрашивает модель (Gemini Nano / Gemma 4 / Gemini Flash) и синтезирует речь (TTS) с прямой потоковой передачей PCM обратно на динамик посоха.

```
       +---------------------------------------------+
       |           Android Смартфон (Pixel / etc)     |
       |  • Точка доступа (Hotspot 2.4 GHz)           |
       |  • IP: 192.168.43.1                          |
       |  • Celestial Companion App (UDP Port 5005)  |
       |  • Режим: PHONE BRAIN (Locked / Active)     |
       +---------------------------------------------+
                              ▲
                              │ Wi-Fi UDP (Порт 5005)
                              │ Голос (INMP441) ──> Приложение
                              │ Речь (TTS PCM)  <── Динамик (MAX98357A)
                              ▼
       +---------------------------------------------+
       |        Посох (Raspberry Pi Pico 2 W)        |
       |  • Подключается к Hotspot смартфона          |
       |  • Автоматический шлюз: 192.168.43.1         |
       |  • Host Mode: [PHONE BRAIN]                  |
       +---------------------------------------------+
```

## 2. Настройка точки доступа на смартфоне

1. Откройте **Настройки Android** ➔ **Сеть и интернет** (или **Подключения**) ➔ **Точка доступа и модем** (Hotspot & Tethering).
2. Зайдите в **Точка доступа Wi-Fi**:
   - **Имя точки доступа (SSID)**: например, `CelestialHotspot` (или любое удобное имя).
   - **Диапазон частот (AP Band)**: **ОБЯЗАТЕЛЬНО выберите 2.4 ГГц** (RP2350 / CYW43439 не видит сети 5 ГГц!).
   - **Безопасность**: WPA2-Personal (или WPA2/WPA3).
   - **Пароль**: задайте пароль (минимум 8 символов).

---

## 3. Настройка прошивки Pico под точку доступа

В файле [`firmware/src/wifi_credentials.h`](file:///c:/projects/personal/hardware-01/celestial_engine_project/firmware/src/wifi_credentials.h) уже предусмотрен резервный профиль `WIFI_FALLBACK_SSID`:

```c
/* Secondary / Fallback Network (Mobile Hotspot for Field / Tethering) */
#define WIFI_FALLBACK_SSID      "CelestialHotspot"  // Имя вашей точки доступа
#define WIFI_FALLBACK_PASSWORD  "ваш_пароль"        // Пароль от точки доступа
#define BRAIN_FALLBACK_SERVER_IP "192.168.43.1"     // Стандартный IP Android Hotspot
#define BRAIN_FALLBACK_SERVER_PORT 5005
```

### Как работает автопереключение:
- Если вы находитесь дома — посох автоматически подключается к домашнему роутеру (`FRITZ!Box` / домашний Wi-Fi).
- Если вы вышли на улицу или выключили домашний роутер — после 3 неудачных попыток посох **автоматически переключается на профиль мобильной точки доступа (`WIFI_FALLBACK_SSID`)** и направляет пакеты на `192.168.43.1:5005`!

## 4. Порядок запуска в полевых условиях

1. **Включите точку доступа** на смартфоне.
2. **Откройте приложение Celestial Companion** на смартфоне.
3. В приложении во вкладке **Dashboard** или **Terminal**:
   - Нажмите кнопку **`LOCK PHONE`** (загорится зелёным).
   - Это сообщает посоху использовать телефон в качестве главного ИИ-мозга.
4. **Подайте питание на посох** (подключите аккумулятор / powerbank к Pico).
5. На OLED-дисплее посоха отобразится:
   - `NET: OK (192.168.43.X)`
   - `HOST: PHONE BRAIN`
6. В приложении статус посоха сменится на **`ONLINE` (зелёный индикатор)**, а в карточке **LIVE HARDWARE TELEMETRY** появятся:
   - `TARGET ENDPOINT: 192.168.43.X:5005`
   - `AI HOST ROUTE: PHONE BRAIN`
   - `LOCK MODE: LOCKED PHONE`
   - Живой индикатор микрофона **INMP441 MIC VU LEVEL**.

---

## 5. Как задавать голосовые запросы

1. **Зажмите кнопку запроса (GP22)** на посохе.
   - Прозвучит звуковой сигнал готовности (высокий чирп 880 Гц).
   - На OLED появится экран **LISTENING** со шкалой уровня громкости голоса.
   - Светодиодные кольца перейдут в режим пульсации записи (VORTEX / PULSE).
2. **Произнесите вопрос в микрофон** (на русском, немецком или английском языке).
3. **Отпустите кнопку**:
   - Посох издаст подтверждающий щелчок и перейдет в режим **PROCESSING**.
   - Аудиопоток передается в телефон, упаковывается в WAV и передается в выбранную ИИ-модель.
   - Телефон синтезирует ответ через нейросетевой TTS и транслирует живой звук на динамик посоха.
   - Текст ответа синхронно отображается на OLED-экране посоха и в чате Companion App.
