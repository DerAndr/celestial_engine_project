## 🌟 What's New in v1.2.0

### 1. Physical Halloween Flask Artifact & 3D Digital Twin
- Physical hardware milestone documented with authentic high-resolution photography (`docs/assets/celestial_flask_physical.png`).
- Built inside an upright transparent acrylic bell flask:
  - Upper bell dome packed with pastel styrofoam diffuser beads (ethereal cosmic aura).
  - 43 concentric WS2812B LEDs (1 center + 6 inner + 12 mid + 24 outer) driven via RP2350 PIO0 SM1 DMA.
  - Solderless breadboard holding the Raspberry Pi Pico 2 W with DuPont wiring harness.
  - Angled 1.3" SH1106 OLED cybernetic HUD in the lower-right displaying `TURN: TUNE | OK`.
  - Bright tactile yellow rotary knob (Bourns PEC11R encoder) mounted through the base.
- Interactive 3D Exploded ↔ Assembled Flask schematic on GitHub Pages with smooth real-time 3D position interpolation (`lerp`).

### 2. Dedicated Halloween Edition Web Simulator (`docs/halloween.html`)
- Standalone showcase featuring a clear maker disclaimer celebrating DIY creativity and retro-futurism.

  - DOOM E1M1 Hellfire
  - Korobeiniki (Tetris 1861)
  - Star Wars Imperial March
  - Zelda Triforce Hymn
  - Ecto Groove (Ghostbusters)
  - Daft Punk Cyber Funk
- Interactive yellow knob with rotation physics, mechanical click sound, and OLED ticker updating.
- Spooky Oracle QUERY button speaking Douglas Adams style prophecies via Web Speech API in English.

### 3. SOTA Gemma 4 E2B (Edge-to-Brain) Architecture Roadmap
- Designated Google's **Gemma 4 E2B** as the target on-device neural engine for zero-cloud offline intelligence.
- Planned acceleration via LiteRT and ExecuTorch utilizing Tensor G4 Edge TPU on Pixel 9 Pro XL and ARM NEON on Raspberry Pi 5.
- Architectural blueprint defined in `docs/tasks.md` (Section 8) decomposing monolithic firmware into clean drivers (`drivers/`, `net/`, `audio/`, `core/`), Core 1 dedicated chiptune audio sandbox, and modern Android MVI companion architecture.
