# Задачи — стабильный голосовой обмен, затем Pi 5

Обновлено 2026-10-11 после новых коммитов и наблюдений пользователя. Посох в целом стабильно работает; запросы, генерация и возврат аудио уже реализованы на ПК.

## Текущее состояние

- **Четвёртое кольцо выброшено пользователем** из-за продолжающейся нестабильности. Рабочая цепочка: 7→12→24, 43 LED, 18% лимит. Ремонт перемычкой — сохранённая история, не текущий монтаж.
- Запись/живой Wi-Fi upload до 60 s; язык и модель выбираются на Pico. Сервер делает STT → LLM → TTS и возвращает речь. Локально в RAM сохраняются только первые 2 s (64 KB).
- Базовая версия пользователя 1.0.15; новая подготовленная 1.0.16 исправляет переполнение ответа, поздние ответы и полноэкранную строку. [036](experiments/036-response-review-and-fullscreen-text.md), [review](reviews/2026-10-11-streaming-review.md).

## Приоритеты

1. **Подтвердить новую пару Pico + сервер v2 на ПК.** Полный длинный ответ, завершение последнего слова, крупная строка на всём OLED, повторный QUERY и отсутствие старых ответов. Не считать программные проверки новым аппаратным PASS.
2. **Перенести тот же сервер на Pi 5.** Сначала прежний роутер, mock-сервер, затем текущие облачные STT/LLM/TTS. У посоха изменить только адрес сервера. [Порядок запуска](pi5-next-stage.md).
3. **Закрепить автономность двух частей.** Pico: меню, эффекты, музыка и локальные фразы без сети; QUERY явно показывает отсутствие сервера. Pi: генерация и транспорт независимо от подключённого посоха. Позже оформить запуск сервера как service и определение адреса.
4. **Довести запросы при плохой связи.** Uplink пока best-effort: добавить подтверждение/восстановление входящих аудиочанков, обработку перестановки и измерение потерь. Проверить реальный обрыв/возврат Wi-Fi и отмену на физическом устройстве. Уточнить отображение причин ERROR.
5. **Локальные настройки/UI.** Сохранение языка, модели, громкости, эффекта; согласованный сброс/отмена и читаемость всей строки. Кириллица сейчас транслитерируется: родной шрифт — отдельная задача.
6. **После переноса — автономный AI и походная сеть.** Отдельно оценить локальные STT/TTS/LLM на Pi 5 и hotspot. Текущий облачный сервер требует интернет; не заявлять его полностью автономным.
7. **Питание и механика.** Питание посоха отдельно от батарейной системы Pi 5; корпус/монтаж после устойчивого голосового сценария. Без списка новых покупок до доказанного блокера.

## Перед следующим аппаратным этапом

- [ ] Подтверждён весь ответ без обрезки/повторов на 1.0.16 + v2.
- [ ] Полноэкранная строка видна и плавно движется.
- [ ] Отмена/повторный запрос не воспроизводит прежний результат.
- [ ] Завершена чистая запись и NVMe-миграция на Pi 5 по [037](experiments/037-rpi5-nvme-stand-alone-migration.md).
- [ ] На Pi работает сначала mock, затем реальный сервер.
- [ ] Локальные функции Pico остаются доступны без сервера.

Переписывание светомузыки **на четыре кольца снято с активного плана**, поскольку четвёртого кольца больше нет. Косметика текущих трёх колец остаётся в бэклоге и не блокирует переход к Pi.
