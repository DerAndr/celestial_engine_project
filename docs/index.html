How the System Works: Staff ⇄ Smartphone & Real-Time Audio/LLM Streaming

PRIMARY CONFIGURATION • UDP PORT 5005

In normal operation, the system requires only two devices: the physical Staff (Raspberry Pi Pico 2 W / RP2350) and your Android Smartphone acting as a mobile Wi-Fi hotspot (10.169.248.1). The staff itself runs bare-metal C/C++ firmware with zero OS overhead: it captures your voice at 16 kHz, streams raw PCM packets over UDP to the phone, and plays back the synthesized voice response, OLED text ticker, and synchronized 43-LED animations in real time.

1. Push-to-Talk & I2S DMA Capture

Holding the green side button (GP9) switches the staff into LISTENING state. Core 1 captures 32-bit I2S frames from the INMP441 mic via PIO0 SM1, decimates them to 16-bit 16 kHz mono PCM, and sends 640-byte (20 ms) UDP packets to port 5005.

2. STT & Local LLM Inference

When the button is released, the host transcribes the speech (Whisper.cpp or Android STT) and feeds the prompt to the active persona. With local models (Ollama qwen2.5:1.5b / gemma4:e2b or browser ONNX WebGPU), tokens are generated with zero cloud dependency.

3. Sentence-Chunked TTS & UDP Pacing

As the LLM streams text, sentences are immediately sent to the neural TTS engine (Piper ONNX or Android TTS) and OLED text packets (0x03) + LED effect IDs (0x01) are dispatched so the staff reacts visually while audio is synthesized.

4. Zero-Stutter 64 KB Ring Buffer Playback

Downlink 16 kHz PCM frames (0x04, 1024 bytes = 32 ms per packet) arrive over UDP into the RP2350's 64 KB circular ring buffer (2.04 s jitter cushion) and stream via DMA to the MAX98357A speaker while the 43 LEDs pulse to the voice envelope.

Deterministic Binary UDP v2 Framing & Network Topology

The smartphone (Google Pixel 9 Pro XL running Android 15) functions as an autonomous Wi-Fi Hotspot (SoftAP) at 10.169.248.1. The Raspberry Pi Pico 2 W connects upon boot via its onboard Infineon CYW43439 802.11n radio. Both devices communicate over bidirectional UDP sockets on port 5005 with custom zero-copy framing, achieving round-trip latency under 18 milliseconds.

Dual Programmable I/O (PIO) I2S Audio Pipelines on RP2350

Celestial Engine Mk.V implements full-duplex digital audio without an external codec. The RP2350 ARM Cortex-M33 utilizes two independent PIO state machines and four DMA channels to stream microphone input and speaker output simultaneously at 16,000 Hz sample rate.

1. Microphone Input (INMP441) PIO0 SM0
  • SCK (Bit Clock): GPIO 10 (Pico Pin 14) — 512 kHz clock
  • WS (Word Select): GPIO 11 (Pico Pin 15) — 16 kHz frame sync
  • SD (Serial Data): GPIO 12 (Pico Pin 16) — 16-bit PCM In
  • Format: 16 kHz, 16-bit Mono PCM (Left Channel)
  • DMA Double-Buffering: 2x 256-sample ping-pong buffers with zero CPU overhead.
2. Speaker Output (MAX98357A) PIO1 SM0
  • BCLK (Bit Clock): GPIO 16 (Pico Pin 21) — 512 kHz clock
  • LRC / WS (Word Select): GPIO 17 (Pico Pin 22) — 16 kHz frame sync
  • DIN (Serial Data): GPIO 18 (Pico Pin 24) — 16-bit PCM Out
  • Power & Gain: 3.2W Class-D into 4Ω neodymium speaker (5V VBUS rail, default 9dB)
  • DMA Streamer: 16-bit signed PCM with automatic hardware clock shutdown on silence.
3. Onboard Hardware Chiptune Synthesizer (Zero-Network Fallback) Core 1 Dedicated

When network connectivity is unavailable, RP2350 Core 1 synthesizes authentic retro arcade square-wave chiptunes directly in C. The synthesizer computes phase accumulators at 16,000 samples/sec, mixing note frequencies, ADSR envelopes, and octave harmonics into the DMA ring buffer. Includes 24 iconic tracks (DOOM E1M1, Tetris, Star Wars Imperial March, Zelda, Daft Punk, etc.) with instant early stop and track skipping.
